# 补丁清单（重装依赖后需重新打）

> 迁移/执行 `pnpm install` 后，`node_modules\.pnpm` 会还原成上游源码，本清单里的修改需要重打。
> 建议：迁移时直接带 `node_modules`（`pack_transfer.ps1 -WithNodeModules`），就不需要重打。

## 1. cortico-world-qq-final@0.6.43

路径：`Cortico\extensions\node_modules\.pnpm\cortico-world-qq-final@0.6.43\node_modules\cortico-world-qq-final\src\`

| 文件 | 修改 |
|---|---|
| `config.ts` | 支持 `"*"` 白名单（groups/privates 全监听标记 listenAll） |
| `world.ts` | 文件消息带发送者（`[文件:xxx] 来自昵称`）、群文件通知带上传者 |
| `world.ts` | `qq_file` 增加 `read`（读文本 ≤64KB） |
| `world.ts` | `web_fetch` 工具（网页正文转纯文本，默认 4000 / 上限 8000 字符） |
| `world.ts` | `qq_video` 工具（Grok Imagine 视频，默认 1080p，`quality=sd` 为 480p；错误提示余额不足） |
| `world.ts` | `qq_group_mode` 工具（free/mute 群发言模式） |
| `world.ts` | 自由群（free）非@消息 3 秒静默后推送；安静群（muted）除 @ 外全部不推 |
| `world.ts` | 主人 `//0~//3` 切换对话思考模式（none/low/high/max），事件 meta 带 reasoningEffort |
| `world.ts` | 兜底自动发送：回合结束模型只输出文本没调 qq_send 时，自动发到待回复会话 |
| `world.ts` | 图片下载上限 2MB（避免请求体超限 413） |
| `world.ts` | GIF 拆帧调用 `<AiQQ>\tools\gif_frames.py`（路径依赖，迁移需 rebind） |
| `qzone.ts` | 恢复 `repliedComments/handledAtComments/commentedFeeds` 持久化（重启不重复回评论） |
| `qzone.ts` | 评论 + 楼中楼一起遍历，回楼中楼带上级评论上下文 |
| `normalize.ts` | `sub_type=1` 表情包处理（不是 subType）；GIF 拆帧转拼图 |
| `qzone.ts` | 空间图片本地路径转 base64（发说说可用本地图） |
